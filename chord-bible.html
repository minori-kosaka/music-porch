各和音の性格・構成・純正律調整ヒントをまとめました。
合奏前のウォームアップや、パート練習の参考にどうぞ。

上記の cent 値は12平均律を基準（0 cent）とした純正律との差です。アンサンブルでは各音の役割に応じてこれらの調整を行うことで、倍音が揃い「鳴る和音」になります。

三和音
長三和音 メジャー / -dur
根音 → 長3度 → 完全5度
明るく安定した響き。アンサンブルの要となる和音です。
最も重要なのは第三音を担当するパートの意識。平均律より約14セント低く取ることで倍音が揃い、和音が「ビーン」と鳴り出します。合奏でなんとなく濁るときは、まず第三音を確認してください。第五音は根音・第三音が正しく取れれば自然と揃います。

第三音−14 cent長三度は純正律で低め
第五音+2 cent完全五度はわずかに高め
短三和音 マイナー / -moll
根音 → 短3度 → 完全5度
暗く内省的な響き。長三和音と全く逆方向の調整が必要なため、曲中で長短が切り替わる箇所は特に注意が必要です。短三度の第三音を高めに取り損ねると、明るくも暗くもない曖昧な響きになります。ピアノ的な平均律感覚のままでは短和音の深みは出ません。

減三和音 ディミニッシュ / -dim
根音 → 短3度 → 減5度
緊張感と不安定さを持つ和音。「どこへ向かうのか」を全員が共有することが最重要です。減五度の音程はぶつかりが強く、奏者が無意識に音を引っ込めがちですが、むしろ積極的に鳴らすことでフレーズの方向性が生まれます。解決先の和音に向かって音程を引っ張るイメージで演奏してください。

増三和音 オーギュメント / -aug
根音 → 長3度 → 増5度
浮遊感と神秘的な響き。長三度が2つ重なる対称的な構造のため、どの音が根音かを全員が共有しないと響きがばらつきます。指揮者やアレンジャーの意図する解決先を確認してから演奏しましょう。増五度は平均律より低めに取りすぎると濁るため、各パートが倍音に耳を傾けることが重要です。

四度和音 サスペンデッド4th / -sus4
根音 → 完全4度 → 完全5度
第三音の代わりに完全四度を使う浮遊した響き。解決先の三和音（dur/moll）を意識した音程感で演奏することが大切です。四度音はほぼ平均律通りでよいですが、解決への期待感を出すには全体のダイナミクスと音色のコントロールが鍵になります。

強い解決感を持つ最重要和音。最大のポイントは第七音を約31セント低くとること。この調整幅は全和音の中で最大です。第七音が高すぎると解決感が薄れ、音楽の「流れ」が止まります。また長三度（−14セント）との組み合わせで、和音全体が前のめりに解決へ向かう緊張感が生まれます。主和音への解決の直前ほど意識してください。

長七和音 メジャーセブンス / -maj7

短七和音 マイナーセブンス / -m7
